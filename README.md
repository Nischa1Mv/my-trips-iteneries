# Vizag → Deomali

Trip notes for a two-day motorcycle run from Visakhapatnam to Deomali,
Odisha's highest peak, out via Araku and Balda and back on NH26.

Single self-contained `index.html`. No build step, no dependencies.
Fonts load from Google Fonts; everything else is inline.

## What's in it

- Day-by-day timings with riding and walking distances
- A live checkpoint tracker that works out what still fits before the 18:00 gate
- Fuel and budget calculators, saved in the browser via `localStorage`
- Food, medkit and group logistics for six people on three bikes

## Publishing

Pushed to the `main` branch and served by GitHub Pages from the repository root.
